### Pertanyaan
1. Single Linked List memiliki satu pointer yaitu next yang hanya dapat menunjuk ke node berikutnya sehingga traversal hanya dapat dilakukan dari depan ke belakang. Sedangkan Double Linked List memiliki dua pointer yaitu next dan prev, sehingga traversal dapat dilakukan dua arah yaitu dari head ke tail maupun dari tail ke head. Double Linked List lebih fleksibel dalam proses penambahan dan penghapusan data karena dapat mengakses node sebelumnya secara langsung.
2. Atribut next digunakan untuk menyimpan alamat node setelah node saat ini sehingga traversal dapat bergerak maju. Sedangkan atribut prev digunakan untuk menyimpan alamat node sebelumnya sehingga traversal dapat bergerak mundur. Kedua pointer tersebut juga berfungsi untuk mempermudah manipulasi node saat proses penyisipan maupun penghapusan data pada Double Linked List.
3. Konstruktor pada class DoubleLinkedList berfungsi untuk menginisialisasi linked list dalam keadaan kosong dengan mengatur nilai head dan tail menjadi null. Hal ini menandakan bahwa belum terdapat node pada linked list saat program pertama kali dijalankan.
4. Karena ketika linked list kosong lalu ditambahkan satu node pertama, maka node tersebut menjadi satu-satunya data pada linked list. Oleh sebab itu head dan tail harus menunjuk ke node yang sama karena node tersebut sekaligus menjadi node pertama dan node terakhir.
