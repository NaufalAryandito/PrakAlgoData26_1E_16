1.tidak harus ada method. Class bisa cuma buat simpan data (atribut) saja. Tapi kalau ada method-nya, biasanya jadi lebih rapi buat olah datanya.
2. kode tersebut berfungsi untuk mendeklarasikan dan menginstansiasi sebuah array bernama arrayOfMahasiswa yang dapat menampung 3 elemen (objek) bertipe class Mahasiswa.
3. di kode tersebut tidak memiliki konstruktor yang jelas, tapi bisa pemanggilan karena java secara otomatis menyediakan default constructor.
4. Kode tersebut melakukan instansiasi objek pada indeks ke-0 dari array (new Mahasiswa()) dan dilanjutkan dengan pengisian nilai (assignment) ke masing-masing atribut objek tersebut, yaitu NIM, Nama, Kelas, dan IPK secara manual.
5. Pemisahan ini bertujuan untuk menerapkan prinsip Separation of Concerns atau pemisahan tanggung jawab. Class Mahasiswa berperan sebagai model/template data (Blueprint), sedangkan class MahasiswaDemo berperan sebagai driver class yang berisi fungsi main untuk menjalankan logika program, seperti input/output dan manajemen array.
